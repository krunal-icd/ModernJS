# Manuals and Specifications – Simple Hinglish Summary

Source: https://javascript.info/manuals-specifications

## Main baat
Ye tutorial aapko JavaScript **step-by-step seekhne** me help karta hai. Basics aane ke baad aapko **dusre resources** ki zarurat padegi. Ye page unhi resources ke bare me hai.

## 1. Specification (ECMA-262)
- Ye JavaScript ki **official rulebook** hai. Isme language ki sabse detailed aur sahi information hoti hai.
- Ye bahut formal hai, isliye shuru me samajhna mushkil hai. **Roz ke use ke liye nahi hai.**
- Jab kisi cheez ki 100% pakki jankari chahiye, tab ye best source hai.
- Har saal nayi version aati hai. Beech me latest draft yahan milta hai: https://tc39.es/ecma262/
- Naye aur upcoming features (proposals) yahan milte hain: https://github.com/tc39/proposals
- Browser ke liye aur bhi specifications hain, jo tutorial ke second part me cover hoti hain.

## 2. Manuals (MDN)
- **MDN (Mozilla) JavaScript Reference** sabse popular manual hai. Isme examples ke saath har function/method ki detail milti hai.
- Link: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference
- **Tip:** Google me seedha likho **"MDN parseInt"** (ya koi bhi term). Ye sabse fast tarika hai.

## 3. Compatibility Tables
JavaScript me naye features aate rehte hain, to check karna padta hai ki wo **sab browsers me chalenge ya nahi.**
- **caniuse.com** → har feature ka browser support table.
- **kangax.github.io/compat-table** → language features aur unko support karne wale engines ka table.

## Quick Summary
| Kaam | Kahan dekhein |
|------|---------------|
| Language ke exact rules | ECMA-262 Specification |
| Function/method ka example ke saath samjhana | MDN |
| Feature browser me chalega ya nahi | caniuse.com / compat-table |
| Naye upcoming features | tc39 proposals |
