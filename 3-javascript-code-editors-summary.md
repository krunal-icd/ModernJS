# Code Editors – Simple Hinglish Summary

Source: https://javascript.info/code-editors

## Main baat
Code editor wo jagah hai jahan programmer **sabse zyada time spend karta hai.** Editors do main type ke hote hain: **IDE** aur **Lightweight editor.** Kai log dono use karte hain.

## 1. IDE (Integrated Development Environment)
- Ye ek **powerful editor** hai jo poore **project** ke saath kaam karta hai, sirf ek file ke saath nahi.
- Features:
  - Project ki saari files load karna aur unke beech navigate karna
  - Poore project ke hisaab se **autocompletion**
  - **git** jaise version control ke saath integration
  - Testing environment aur dusre project-level tools
- Options:
  - **Visual Studio Code** → free, cross-platform
  - **WebStorm** → paid, cross-platform
  - **Visual Studio** → paid, sirf Windows, .NET ke liye best (free version: Community). **VS Code se alag hai**, confuse mat hona.
- Zyadatar IDEs paid hote hain lekin **trial period** milta hai.

## 2. Lightweight Editors
- IDE jitne powerful nahi, lekin **fast, simple aur elegant** hote hain.
- Kaam: koi file **turant kholna aur edit karna.**
- IDE start hote waqt zyada data load karta hai, isliye ek file ke liye lightweight editor tez hota hai.
- Plugins lagane par inme bhi IDE jaise features aa jate hain, isliye dono ke beech **strict line nahi hai.**
- Options:
  - **Sublime Text** → cross-platform, shareware
  - **Notepad++** → Windows, free
  - **Vim** aur **Emacs** → bahut acche hain, agar chalana aata ho

## 3. Kaun sa editor chunein?
- Editor ka choice **personal hota hai**, projects aur habits par depend karta hai. Bahut bahas mat karo.
- Author ki raay:
  - **Frontend** zyada karte ho to → **VS Code**
  - Dusri language/platform zyada aur frontend thoda → XCode (Mac), Visual Studio (Windows) ya JetBrains family (WebStorm, PHPStorm, RubyMine, etc.)

## Quick Summary
| Type | Kaisa hai | Example |
|------|-----------|---------|
| IDE | Powerful, project-level, thoda heavy | VS Code, WebStorm, Visual Studio |
| Lightweight | Fast, simple, single file ke liye best | Sublime Text, Notepad++, Vim |

**Beginner ke liye:** frontend/JavaScript seekh rahe ho to **VS Code** se start karo.
